## 📌 Project Overview

This is the personal portfolio of **Yasith Hasarinda (Hass Dev)**, designed to highlight my expertise as a **Full Stack Developer** and a BSc (Hons) IT Undergraduate. The portfolio features a visually stunning interface with modern animations, 3D elements, and smooth scrolling experiences.

---

## 🎯 Objectives

- Showcase my personal and academic projects
- Highlight my skills in Full Stack Development (MERN Stack, Java, Spring Boot, etc.)
- Provide an immersive user experience with 3D graphics and animations
- Create an easily navigable platform for potential clients and employers to contact me

---

## 🛠️ Technology Stack

| Category | Technology |
|----------|------------|
| **Frontend Framework** | React 19, Vite |
| **Styling** | Tailwind CSS v4, PostCSS |
| **Animations** | Framer Motion, GSAP |
| **3D Graphics** | Three.js, React Three Fiber, Spline |
| **Smooth Scrolling** | Lenis |
| **Icons & Typography** | Lucide React, React Icons |
| **Other Integrations** | EmailJS (Forms), Rive (Animations) |

## 🗂️ Project Structure

**`src/`**
- `assets/` — Images, 3D scene codes, and other static assets
- `components/` — Reusable React components (`Hero.jsx`, `About.jsx`, `Navbar.jsx`, `Projects.jsx`, etc.)
- `App.jsx` — Main application layout and routing
- `index.css` & `App.css` — Global styles and Tailwind directives

**Configuration Files**
- `vite.config.js` — Vite configuration
- `package.json` — Project dependencies and scripts

## 🚀 Getting Started

### Step 1 — Clone the Repository

```bash
git clone https://github.com/IT24101654/Hass.dev.git
cd Hass.dev
```

### Step 2 — Install Dependencies

```bash
npm install
```

### Step 3 — Run the Development Server

```bash
npm run dev
```

Open your browser and visit:
http://localhost:5173/
